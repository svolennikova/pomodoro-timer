# 🍅 Помидоро-таймер

Таймер по методу Помодоро в одном HTML-файле, без зависимостей.

- Помидор «созревает» из зелёного в красный по ходу сессии фокуса
- Режимы: Фокус → Короткий перерыв, после каждого 4-го помидора — Долгий перерыв
- Свои длительности сессий и быстрые пресеты (25/5/15, 50/10/30, 15/3/10)
- Список задач: помидоры засчитываются текущей задаче
- Счётчик помидоров за сегодня
- Личный кабинет: профиль, общая статистика и по каждой задаче — сколько помидоров и минут фокуса на неё ушло
- Экспорт и импорт данных в JSON — чтобы сохранить копию или перенести на другое устройство
- Горячие клавиши: `Пробел` — старт/пауза, `R` — сброс

Настройки, задачи, статистика и профиль хранятся в `localStorage` браузера.

## Запуск

Просто откройте `index.html` в браузере.
